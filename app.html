Detalhes Técnicos

Desenvolvimento Mobile Robusto e Multiplataforma

O SmartGlycoAI é construído com Flutter, estabelecendo uma arquitetura de base sólida com regras estritas de análise estática e integrações nativas otimizadas para Android e iOS.

Tecnologias Utilizadas

📱

Flutter & Dart

Frontend unificado e lógica partilhada com regras estritas.

🤖

Android (Kotlin)

Módulo nativo gerido com Gradle Kotlin DSL e perfis otimizados.

🍏

iOS (Swift)

Estruturado em Xcode com gestão de assets e ciclo de vida nativo.

Compilar e Correr

# Obter dependências

$ flutter pub get

# Executar em ambiente de desenvolvimento

$ flutter run

# Compilar versões de produção (Release)

$ flutter build apk --release

$ flutter build ipa --release
