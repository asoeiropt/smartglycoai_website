Interaction Framework

The Interaction Cycle (Abowd & Beale)

Mapping SmartGlycoAI into the four major components of an interactive system, where interaction is seen as the translation between languages[cite: 137].

USER (Task)
👤

Goal Formulation

The diabetic patient needs to know how much insulin to administer for the meal in front of them.

Articulation Phase
INPUT
📱

Interface Manipulation

The user articulates the task within the input language by tapping the camera shutter button on the touchscreen[cite: 138].

Performance Phase
OUTPUT
👁️

State Communication

The new system state is translated to the output language: a visual modal displaying the suggested insulin dose[cite: 138].

Observation Phase
SYSTEM (Core)
🧠

System Processing

The input is translated into Core operations: Computer Vision algorithms analyze the image, and the dose math is executed[cite: 138].

Presentation Phase
