Frontend Architecture

Robust Cross-Platform Mobile Development

SmartGlycoAI is built with Flutter, establishing a solid foundational architecture with strict static analysis rules and optimized native integrations for the best user experience.

User Flow

📸

1. Snap

Take a photo of your meal. Our Computer Vision AI instantly recognizes the food and estimates the total carbohydrates.

⌚

2. Sync

Your Continuous Glucose Monitor (CGM) sensor seamlessly syncs your real-time blood sugar levels via Bluetooth.

💉

3. Dose

Receive a precise, AI-calculated insulin dose recommendation tailored to your meal and current biometrics.

Tech Stack

📱

Flutter & Dart

Unified frontend and shared logic with strict UI rules and custom component rendering.

🤖

Android (Kotlin)

Native module managed with Gradle Kotlin DSL and optimized compilation profiles.

🍏

iOS (Swift)

Structured in Xcode with seamless asset management and native iOS lifecycle bindings.

Application Versions

Build & Run

bash — flutter

# Get dependencies

~/SmartGlycoAI $ flutter pub get

# Run in development environment

~/SmartGlycoAI $ flutter run

# Build production versions (Release)

~/SmartGlycoAI $ flutter build apk --release

~/SmartGlycoAI $ flutter build ipa --release
