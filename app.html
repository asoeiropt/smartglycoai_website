The App
Technical Details

Robust Cross-Platform Mobile Development

SmartGlycoAI is built with Flutter, establishing a solid foundational architecture with strict static analysis rules and optimized native integrations.

Tech Stack

📱

Flutter & Dart

Unified frontend and shared logic with strict rules.

🤖

Android (Kotlin)

Native module managed with Gradle Kotlin DSL and optimized profiles.

🍏

iOS (Swift)

Structured in Xcode with asset management and native lifecycle.

Build & Run

# Get dependencies

$ flutter pub get

# Run in development environment

$ flutter run

# Build production versions (Release)

$ flutter build apk --release

$ flutter build ipa --release
