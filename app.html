Detalhes Técnicos Technical Details

Desenvolvimento Mobile Robusto e Multiplataforma Robust Cross-Platform Mobile Development

O SmartGlycoAI é construído com Flutter, estabelecendo uma arquitetura de base sólida com regras estritas de análise estática e integrações nativas otimizadas. SmartGlycoAI is built with Flutter, establishing a solid foundational architecture with strict static analysis rules and optimized native integrations.

Tecnologias Utilizadas Tech Stack

📱

Flutter & Dart

Frontend unificado e lógica partilhada com regras estritas. Unified frontend and shared logic with strict rules.

🤖

Android (Kotlin)

Módulo nativo gerido com Gradle Kotlin DSL e perfis otimizados. Native module managed with Gradle Kotlin DSL and optimized profiles.

🍏

iOS (Swift)

Estruturado em Xcode com gestão de assets e ciclo de vida nativo. Structured in Xcode with asset management and native lifecycle.

Compilar e Correr Build & Run

# Obter dependências # Get dependencies

$ flutter pub get

# Executar em ambiente de desenvolvimento # Run in development environment

$ flutter run

# Compilar versões de produção (Release) # Build production versions (Release)

$ flutter build apk --release

$ flutter build ipa --release
