## 🚀 About the Project
**SmartGlycoAI** is a cross-platform mobile application designed to alleviate the daily cognitive burden of Type 1 Diabetes (T1D) management. By integrating **Computer Vision** (for instant meal carbohydrate estimation via photo capture) and **Continuous Glucose Monitoring (CGM)** biometrics, the app provides precise, automated insulin dose recommendations.

This repository hosts the **Project Portal** website, tracking all academic deliverables, user research, interface analysis, and frontend architecture stages throughout the semester.

---

## 📂 Project Portal Structure

The portal is structured as a multi-page interactive web application built with modern web standards:

*   **`index.html`** — Main project dashboard containing milestone progress, development phases, and quick links.
*   **`app.html`** — Front-end and cross-platform architecture documentation (Flutter/Dart, native Android/iOS integrations, and user flow).
*   **`stage1.html`** — Stage 1 deliverable: Project Proposal, problem definition, target users, and market competition.
*   **`stage2.html`** — Stage 2 deliverable: User & Task Analysis, figurative personas, and preliminary research.
*   **`glossary.html`** — Medical and technical terminology glossary (CGM, T1D, ICR, basal/bolus insulin).
*   **`developers.html`** — Team profile and credentials.
*   **`main.js`** — Global interactive scripts (Dark mode toggle, mobile navigation, and interview modals).

## 🛠️ Tech Stack & Design System

*   **Markup & Layout:** HTML5, Tailwind CSS (via CDN)
*   **Animations:** AOS (Animate On Scroll Library)
*   **Target Mobile Framework:** Flutter / Dart (cross-platform)
*   **Design Focus:** Human-Centered Design, Accessibility (WCAG compliance), and clean UI/UX standards tailored for healthtech applications.
