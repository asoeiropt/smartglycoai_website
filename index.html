Desenvolvimento Mobile Robusto e Multiplataforma

O SmartGlycoAI é construído com Flutter, estabelecendo uma arquitetura de base sólida com regras estritas de análise estática e integrações nativas otimizadas para Android e iOS.

Tecnologias Utilizadas

A base tecnológica que garante a performance e escalabilidade do projeto.

📱

Flutter & Dart

Frontend unificado e lógica de negócio partilhada com regras estritas (analysis_options.yaml).

🤖

Android (Kotlin)

Módulo nativo gerido com Gradle Kotlin DSL (build.gradle.kts) e perfis de manifesto otimizados.

🍏

iOS (Swift)

Estruturado em Xcode com gestão precisa de assets visuais e ciclo de vida gerido no AppDelegate.

Arquitetura do Repositório

/android

Utilização moderna do Kotlin Script (KTS) para builds. Inclui manifestos separados para debug, main e profile, garantindo permissões exatas apenas quando necessárias. O ponto de entrada nativo é a MainActivity.kt.

/ios

Totalmente configurado para o Xcode Build System. Transições de splash screen configuradas no LaunchBackground e ícones rigorosamente dimensionados no AppIcon.appiconset.

Raiz & Ferramentas

O ambiente está preparado para debugging avançado com as definições do devtools_options.yaml, assegurando uma monitorização de performance de alto nível.

Compilar e Correr

# Obter dependências

$ flutter pub get

# Executar em ambiente de desenvolvimento

$ flutter run

# Compilar versões de produção (Release)

$ flutter build apk --release

$ flutter build ipa --release
